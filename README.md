# CUSTOMER_CHURN_DETECTION
Group project developed during the Master’s in Big Data, Data Science and Business Analytics, focused on building a predictive model to anticipate customer churn in a telecommunications company.
The main objective was to design a binary classification model capable of identifying customers with a high probability of leaving the company, enabling proactive retention strategies. A key requirement of the project was the use of interpretable models, avoiding “black-box” approaches to ensure a clear understanding of how each variable influences churn.
The project involved working with real training and test datasets and followed a complete end-to-end predictive analytics workflow:

Exploratory Data Analysis (EDA) and data cleaning, including identification of outliers and data quality issues
Feature analysis and assessment of relationships with the target variable (churn)
Feature engineering and selection using statistical techniques (including classical methods and regularization approaches such as Lasso)
Development and comparison of interpretable models (e.g., logistic regression) using repeated cross-validation
Model optimization, including selection of the optimal classification threshold
Interpretation of results to identify the key drivers of customer churn
Generation of predictions on a real test dataset without target labels, as part of a competitive team-based evaluation

This project combined machine learning, statistical analysis, and business-oriented thinking, with a strong focus on model interpretability and real-world applicability for decision-making.
